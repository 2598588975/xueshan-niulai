# 对局结构：让动作改变处境

用于需要解释优势变化、胜负或达成目标的打戏。下面是新增创作方法，不是原作者原文。单次动作、过桥反应或用户已经锁定的完整编排，只补必要因果与连续状态。

## 先辨认范围与结果

- **单次动作**：一次攻击、闪避、落地等，交代动作与直接后果即可。
- **对局片段**：完成一次压制、脱险或试探；结尾可以仍在战斗，不强行判胜负。
- **完整对局**：说明目标怎样达成、对方为何无法继续阻止，以及结束状态。

目标可以是守住通路、夺回物件、拖延、救援、切磋分高下。失败后果要来自用户剧情；独立创作可用动作能够表现的局部后果，必要时简短说明假设。不要为了显得宏大临时新增人质、死亡、宿怨或规则。

## 建立最小对局骨架

内部先回答：谁要什么；对方怎样阻碍；开场谁掌握什么优势；什么已知条件可能改变优势；本段结束到哪里。未知的最终胜负与本段无关时可留空。用户只要提示词时，骨架转化为可见行为，不另附分析表。

| 可选阶段功能 | 需要变化的东西 | 可拍的证据 |
| --- | --- | --- |
| 建立预期或试探 | 谁快、谁强、谁控制距离 | 一次攻击逼出真实防守选择 |
| 压制 | 退路、距离、可用动作减少 | 后退到地标旁、支撑被迫改变 |
| 危机或反转 | 原优势因已知条件失效 | 同一破绽被识别、地形封住习惯出口 |
| 付出代价或调整 | 原办法不能无限复用 | 呼吸、步幅、持物或能量出现限制 |
| 结果落点 | 谁达成目标，谁还能阻止 | 通路被清出、越过防线、止战或下一轮对峙 |

按需要选取、合并、换序或省略。15 秒可以只表现“压制 → 识别破绽 → 暂时脱险”；切磋、救援和单方面追击有各自结构，不套五回合。叙事阶段、镜头和时间段没有固定的一对一关系。

可复用的内部字段：

```text
范围与既定结果：
目标与失败后果：
开场优势及证据：
阶段：占优方／行动选择／对方应对／新增信息／结束状态
反转：前置条件／触发动作／为何旧优势失效
代价：可见变化／下一动作受何限制
结束：位置与朝向／持物与形态／消耗与能量／未结束运动
```

## 反转要能沿画面追溯

用一个够清楚的条件支撑反转：大角色横扫后制动慢；小角色的惯常侧让出口被墙封住；握持点松脱；追击者被已出现的地形迫使改变路线。先看见条件，再看见角色利用它，最后看见优势变化。

能力底牌只能沿用用户设定，或在允许原创时提前建立征兆与规则。没有伏笔的变身、突然恢复、临时免疫不能替代胜负依据。用户规定输赢时，设计达到该结果的路径，不另改结局。

信息差可选：观众先看到背后裂缝、角色随后察觉，会产生等待感；也可让观众跟角色同时发现。仅写角色知道的信息，除非故事要求盲打、误判或诱敌。不要用文字宣称“紧张”，要让风险在空间或动作里出现。

## 损耗是一条连续状态

每次重要交锋检查是否改变支撑、距离、体力、装备、伤势或能量；未改变就不添一项。只保留后续会用到的状态。

| 状态变化 | 下一拍需要继承的影响 |
| --- | --- |
| 右腕被扭到、握力下降 | 右手不能立刻恢复同强度抓握；改支撑、换手或明确恢复机制 |
| 连续冲刺后喘息 | 蓄力需要空隙，步幅或追击距离变化 |
| 护甲松脱、短刀落地 | 松脱继续存在；拾取或换持要有过程 |
| 能量爆发后变弱 | 余光减弱，下一次输出受限；有恢复规则才恢复 |
| 被逼到墙边或错过出口 | 失位也是代价，不必转为受伤 |

切磋可只用消耗和失位。夸张动画也要在同一套规则内；无用户要求时不升级到血腥伤害。多段生成若有实际结果，以画面末态为准，明确标出阻碍续接的重大偏差，不假装计划已经执行。

## 记忆点与台词按功能加入

标志性动作不靠招式名独立成立。写清发动部位、路径、目的与破绽，再决定是否命名。同一招再次使用时改变一个有意义的条件：第一次横撞被侧让，第二次先封侧让路线。也允许一次性动作，不强制“失效—改良—绝杀”。

台词只在有呼吸与动作空间时使用，可承担诱导、揭露判断、打断冲动或结束切磋。已经能靠动作表达的信息不再复述；无台词任务保持无台词，保持说话者、时机与已知声线一致。
