# 动作与镜头语法

这是从来源案例提炼并延伸的创作工具。按当前动作选用，不能把所有术语和效果叠进同一条提示词。

## 一、先设计双方的动作差异

用体型、目标、擅长范围和情绪决定动作。以下是可替换组合，不是固定人设。

| 动作类型 | 发动方式 | 防守与转向 | 可见的身体及环境反馈 |
| --- | --- | --- | --- |
| 厚重、压迫型 | 大步推进、髋肩带动宽幅攻击 | 制动较慢，依靠体量封锁空间 | 重心下压、脚下压痕、衣物延迟摆回 |
| 轻巧、贴身型 | 小步调整、短距离让线、贴近空隙 | 借对手动作变位，落地迅速回收架势 | 足尖点地、衣摆转弧、较小接触范围 |
| 爆发、超能型 | 先有身体聚力或能量源，再产生位移 | 爆发后出现可辨认的余势和状态变化 | 局部光照先变，随后冲击、抛飞、扩散 |
| 连续追击型 | 前倾加速、反复蹬地，接力使用地形 | 转弯、跨障、反弹改变追击线路 | 地面痕迹串联，前景快速掠过，目标距离变化 |

强者也可以灵巧，轻角色也可以重击。选择由人物设定决定，体型只提供观众理解力学的一条线索。

## 二、把一个动作写成可见过程

**起势 → 发力 → 路径 → 对手选择 → 接触/错身 → 位移 → 收势。**

例：一名体型较大的角色前脚压地，肩髋带动横向挥击；对手先缩短身体轮廓，从攻击内侧滑入。挥击落空的旋转迫使大角色向侧面跨步制动，轻角色在其转身之前移到侧后方。衣物和尘屑沿原方向继续运动，双方重新面向彼此。

这段的重点是动作之间的依赖：躲闪路线由攻击线决定，后续变位由对手尚未停止的旋转创造。自由改写人物与出招，保留这种依赖。

### 连续高速攻防

- 一组连续动作以一个主要意图贯穿：逼近、压制、脱离、抢救或打开通路。
- 对手能改变局势：拦截、追踪、变招、抓握、逼到障碍旁，不能始终被动站立。
- 连招中每个新动作承接上一动作的姿态与动量。手脚、道具与双方距离不能无过程重置。
- 观众先读到攻击方向，再读到应对方式，最后读到结果；不要求所有环节占相同时间。

### 贴身与缠斗

明确谁控制什么接触位置、谁在支撑、谁失衡。通过支撑脚挪动、躯干扭转、肩部顶住、抓握松脱等可见变化交代力的转移。机位保持交互部位可见，绕拍由身体旋转或观察需要触发。

### 腾空与地形接力

先交代蹬离点或外力来源，再给飞行方向、弧线与落点。空中姿态变化有身体旋转或技能机制支持。落地写压缩缓冲、滑移制动、扬起物和再启动。起跳、飞行、落地可分镜，也可让摄影机连续跟随；按用户要求选择。

### 能量与冲击

按“聚集位置 → 局部征兆 → 身体发动 → 接触或发射 → 外力位移 → 扩散与消退”组织。能量颜色应影响附近皮肤、衣物和地面。冲击波与受击位移具有方向；特效强度与戏剧阶段对应。奇幻可以夸张尺度，但前后遵循同一规则。

## 三、高速感、重量感和可读性同时成立

| 要让观众感到什么 | 可写进提示词的证据 |
| --- | --- |
| 突然变快 | 原本收住的身体快速释放，重心前移，摄影机加速跟随，背景掠动增强 |
| 速度持续 | 主体在画面中相对稳定，前景和背景产生不同速度的视差，地面接触点连续后移 |
| 接触扎实 | 明确交会点，接触一瞬肢体受压或姿态改变，随后受力者和附属物沿合理方向移动 |
| 体量沉重 | 启动、转向和制动有惯性，地面、衣物与小挂件依次响应 |
| 轻巧灵活 | 攻击将到前小幅移开，支撑点及时更换，落地快速稳定并找到下一条路线 |
| 爆发特别强 | 爆发前有收束，接触后放大位移和环境响应，结尾有足够时间看清后果 |

动作模糊沿运动方向出现，保留人物身份、主要肢体轮廓和决定性接触。短暂速度变化用来强调事件；不要用全程慢放承担高速打戏的所有表现。

## 四、摄影机动作与拍点绑定

| 动作拍点 | 主要摄影机任务 | 起点、轨迹与结束信息 |
| --- | --- | --- |
| 人物迎面逼近 | 传达压力并维持距离关系 | 从正面或斜前方后退，速度随逼近变化，结束时仍能看见目标方向 |
| 水平交锋或追赶 | 显示攻击线与双方速度差 | 沿主体一侧平行跟随，保留前后间距，接触时略调整角度 |
| 蹬地、滑步、急停 | 看清支撑点和摩擦 | 低机位短距跟脚，沿地面方向运动，随后抬起接人物下一动作 |
| 绕身、抓握、挣脱 | 看清身体交互 | 随躯干旋转小幅绕拍，结束于能看见脱离路径的位置 |
| 起跳、上冲、击飞 | 建立垂直距离 | 从起跳点向上抬摇或升起跟随，保留地面参照，再交代最高点或落点 |
| 蓄力、发现目标 | 聚焦行动动机 | 稳定中近景或缓慢推进，结束于眼神、呼吸或能量征兆 |
| 突然转移威胁 | 引导注意力转向新位置 | 按人物视线或声音方向快速转向，结束后立即建立新的稳定构图 |
| 重击或坠地 | 让接触可读并传达余震 | 保持接触位置可见，碰撞一刻短促震动，随后恢复并展示结果 |
| 大范围破坏或胜负落定 | 显示动作后果 | 跟随击退方向或适当拉开，看到落点、痕迹与最后人物关系 |

切镜后重新确认左右或前后关系；必要的越轴用连续绕拍、跟随人物穿过空间或重新建立全景来交代。

焦段可作视觉语言提示：约 12–24mm 的广角感适合夸张纵深与近距离体量，35–50mm 感适合读清双人关系，85–135mm 感适合集中脸部和压迫感。它们是可选观感描述，不是平台必然精确执行的光学参数；不要每镜头机械填一枚镜头。

## 五、把环境、材质和情绪接入动作

环境响应从实际接触点发生。雪粉、细尘更容易形成拖尾；积水被脚和落物排开；碎石、冰屑具有可跟随的抛出方向；金属在撞击处变形或震颤。破坏强度由角色力量与场景设定决定。

毛发、衣摆、尾巴和饰物是动作方向与加速度的可见证据。它们随主动作启动并延迟回落，不能每一拍都无规律飘动。

情绪改变动作：焦急救援可以缩短试探，轻视可以表现为较松的防守，发现危险会导致呼吸与重心先变化。情绪特写安排在观众需要理解行动选择的时刻。

画面前景提供擦过镜头的速度线索，中景保留交手主体，背景承接地形和规模。粒子、光和烟雾围绕事件产生与消散，关键动作先让人读清，再展开效果。

## 六、声音跟随同一条动作链

建立环境底声；蹬地和衣物声提示发动；掠过声提示运动方向；接触声与身体及材质响应同步；碎屑、回声和呼吸承接余势。必要时让配乐在蓄力前收束，再随爆发进入。

同一角色的叫喊、呼吸、台词沿用已知声线。短台词放在具备呼吸与动作空间的位置。设计声音时明确它是生成要求，不将文字推断描述成已经试听的事实。
