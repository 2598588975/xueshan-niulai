# 原创迁移示例

以下均为根据学习方法新写的示例，不是原作者提示词。没有外部参考绑定，角色外观由文字定义。不要把角色、胜负、时长或招式套用到用户已有故事。

## 示例 A：15 秒，三维动画，高速攻防转折

演示“时间轴式”：由攻击创造闪避路线，由闪避带出转身，再由转身惯性创造反制机会。

```text
三维动画动作短片，横向宽画幅，总时长 15 秒。角色毛发、布料与石面保留清楚材质，动作允许动画式弹性和夸张幅度。体型高大的岩甲兽穿深灰护甲，右侧站着体型较小的赤狐剑客，赤狐穿青色短外套，短刀始终握在右手。古桥石面略湿，桥边残柱作为空间地标。阴天冷光下，双方轮廓分明。岩甲兽从画面左侧压向右侧的赤狐，赤狐的目标是绕过对手到达桥的另一端。

0–3s｜侧面双人中全景，摄影机向右平行跟拍。岩甲兽两次沉重踏步逼近，右脚压实后肩髋旋转，右臂扫向赤狐上身。赤狐视线盯住对方肩部，压低重心，刀贴近身体，准备进入挥臂内侧。湿石面的鞋底摩擦和甲片声逐渐加快。

3–6s｜切到更低的侧前方，摄影机沿赤狐方向后退。赤狐在扫臂接近时屈膝滑入对手身前，头部与上身从手臂下方通过，左掌短暂撑地稳定方向，迅速收回。岩甲兽挥臂落空，旋转带着上身继续偏转，向侧方跨步制动。赤狐外套向后拖出弧线，地面水珠沿滑行方向飞散。

6–10s｜切至桥边残柱一侧的中景，重新看清赤狐已到岩甲兽侧后。岩甲兽转身，以另一只手抓住赤狐左肩外套。赤狐前冲被扯住，上身后偏，立刻回步卸去拉力，再顺着抓握方向转体脱出半边外套；右手短刀保持朝向地面，不参与接触。摄影机随转体小幅绕行，抓握、失衡与脱离依次可见。衣料绷紧声后接一次急促呼气。

10–13s｜切侧面中全景。赤狐借转体余势跃向残柱，左脚在柱面点踏，反弹越过岩甲兽来抓的手臂。摄影机短距离向上跟随，交代蹬离点、空中弧线和越过对手的路线；披在一侧的外套和尾巴稍后跟上，柱面旧灰向下飘落。

13–15s｜切向桥另一端的斜后方全景。赤狐双脚先后落地，膝髋压低吸收落势，滑出短距离后站稳，左手拉回松脱的外套。岩甲兽在后方转身停住，双方位置已经交换。摄影机稳定下来，保留两者和残柱地标，落地声、细碎水声渐弱，赤狐抬眼确认前路。
```

这里的高潮是完成绕越，按任务选择结果；打戏不必每段都以更大爆炸收尾。

## 示例 B：12 秒，力量爆发，画面与动态配合

演示“画面设定＋动态执行式”。三个镜头合计 12 秒，角色和环境在总设定中只写一次。首镜提供真正起始状态，峰值帧只作视觉目标。

```text
总设定：三维奇幻动画，12 秒，三镜头。银鬃守卫身形高大，穿暗蓝肩甲；赤铜机械兽低伏四足，前胸带圆形装甲。破损高台右侧有一面斜立石壁。夕光从左后方照来，守卫冷白能量与暖色环境形成区分。开场守卫位于左侧，机械兽位于右侧，相距数步。守卫需要击退机械兽，清出高台通道。

镜头 1｜4 秒｜压住退势，再次发动
画面（起始帧）：低机位中全景，守卫左脚在后、右脚在前，双臂抵住机械兽前胸，身体被推得后倾。地面已有两道拖痕，远处石壁清楚可见。
动态：摄影机沿侧面缓慢靠近。守卫先被推进半步，随后压低髋部，后脚蹬稳，把身体从后仰收回到前倾；肩甲、鬃毛继续晃动，呼吸由急变沉。冷白光先在双掌和前臂集中，照亮机械兽胸甲的边缘，细尘从脚边微微抬起。
声音：机械关节挤压声、粗重呼吸和石面刮擦。末半秒背景低频收束，保留守卫一次短促吸气。

镜头 2｜3 秒｜局部接触，力量推出
画面（动作峰值关键帧）：侧前方中景，守卫双掌与胸甲的接触处出现紧凑白光，机械兽前肢刚离地，身体仍朝向守卫，受力方向通向右后方石壁。
动态：从上一镜守卫已经收回重心、双掌抵住胸甲的状态继续。摄影机快速贴近接触侧面，守卫蹬地伸髋，肩部和双臂顺势向前推出；胸甲先局部内压，机械兽随即向右后方滑离并被抬起。接触一瞬略放缓，显出受压和离地；之后恢复高速，冷白冲击沿推出方向扩散。鬃毛、肩甲和脚边尘雾在推击之后才向外甩开。
声音：短促厚重撞击与金属受压声同时出现，紧接一层向远处展开的低频尾声。

镜头 3｜5 秒｜位移、撞壁、余势
画面：从侧面拉开的全景，保留守卫、机械兽运动路线与石壁，能读清飞出方向和剩余距离。
动态：摄影机沿机械兽被推出的方向平行跟随。机械兽沿浅弧线撞上石壁，后背先接触，石壁在接触处裂开，碎片随后向外散开。摄影机在撞击时短促震动，随后稳定；机械兽落回台面，四肢撑地滑移制动，少量碎石继续滚动。末尾构图重新容纳远处站稳的守卫，守卫双臂下降，掌心光减弱，清出的通道清晰可见。
声音：先有逼近石壁的破风，接着石裂、落地与碎片滚动；最后只剩较轻的能量余响和呼吸。
```

## 示例 C：一个短事件

演示“短事件式”，适合接在上一示例之后。

```text
银鬃守卫站在刚清出的高台通道旁，双掌能量已减弱，肩甲与鬃毛仍覆有细尘。中近景，摄影机轻轻推进。他先松开绷紧的肩膀，低头呼出一口气；听到画外一声轻响后抬眼转向通道深处，神情从疲惫变为警觉。转头带起鬃毛，几粒细尘稍后落下，掌心仅剩微弱冷白余光。保留风声、呼吸和远处一声石子滚动，4 秒，无台词。
```

## 示例 D：8 秒一镜到底，沿用同一动作方法

用于迁移，不新增第四种基础格式。它是时间轴式在单个连续镜头中的应用。

```text
三维动画，8 秒，一镜到底。轻装狸猫信使从窄巷左侧冲向右侧出口，高大的木甲守卫在出口前横向拦截。雨后路面薄薄积水，右侧墙上有一段低矮窗台。信使要借窗台越过拦截，守卫始终追踪信使。

0–2s｜同一摄影机在信使侧前方低位后退，保持上身与足部可见。信使连续蹬地加速，腰间小包略晚于身体起伏，细小水花沿跑动方向向后甩出。出口与守卫始终处于画面右后方。

2–5s｜守卫侧跨半步伸臂封路。摄影机顺着信使向墙边偏转的路线向外横移并抬高。信使没有停步，先把前脚落在窗台上，屈膝压缩后弹起，双腿收拢越过拦截的手臂；守卫抬头转肩继续跟踪。摄影机连续上移，保持窗台、手臂和腾空身体的关系可见。

5–8s｜摄影机继续向出口方向移动并缓缓降低，跟着信使落到守卫身后。信使双脚先后着地，短滑一步恢复奔跑，手臂摆动带起小包。守卫转身开始追赶，摄影机恢复侧向跟拍，让两者和已越过的窗台同处一幅画面。脚步、衣物与溅水声连贯，腾空时短暂变轻，落地时重新加重。
```

## 示例 E：15 秒对局片段，反转依靠已出现的破绽

演示“压制 → 识别制动破绽 → 清出通路”。只完成脱险，不判定整场决斗胜负；既有右腕损耗持续影响动作。无台词、无外部参考绑定。

```text
三维拟人动物动画，15 秒，四个镜头。岩甲兽高大宽肩，赤狐剑客矮小灵活，两者保持双足形态。赤狐右腕已有旧伤，右手短刀朝下贴身收住，不用右手撑地或强抓。古桥西端在画面左侧，岩甲兽挡在桥中央，赤狐位于右侧，要穿过左侧通路。桥北沿是矮石栏，摄影机均在桥南侧看向北侧。岩甲兽右脚甲片较重，每次转身急停都需要补一步；开场可见该脚在湿石面留下短拖痕。

0–3s｜南侧双人中全景。岩甲兽从左向右踏步，前脚压实，肩髋带右臂扫向赤狐上身。赤狐屈膝从扫臂下方让过，向桥北沿退半步。摄影机向右平移，保留双方和石栏；挥空的岩甲兽向右多跨一步制动，右脚甲片擦地，拖痕延长。

3–7s｜切同侧中景。岩甲兽转回面向赤狐，左掌推到赤狐左肩。赤狐被推近北侧石栏，左脚后跨稳住，右腕仍贴身保护；双方高度差清楚。推压结束后岩甲兽左掌收回，赤狐呼吸变急，视线落到对方再次拖滑的右脚，而非凭空发现新能力。

7–11s｜切南侧稍低的中全景。岩甲兽再次发动横扫。赤狐先抬肩作向北退的假动作，引得对方转髋追向石栏，再屈膝向南侧斜步，从扫臂下方穿到岩甲兽身前的空隙；右手短刀始终收住。岩甲兽挥空后右脚滑出，补步制动时暂时不能转身，赤狐借这一空隙继续向西跨过其侧边。摄影机沿桥向左跟拍，交代这次换位与前一次拖痕的关系。

11–15s｜切同侧拉开的全景。赤狐落步后短滑制动，再向西端通路迈出两步；右腕仍收在腹侧，胸口起伏未消失。岩甲兽在后方稳住支撑，转身准备再追。摄影机容纳两者及同一石栏，明确赤狐已经越过封锁、对局尚未结束。保留脚甲刮擦、落步和喘息，不用胜利台词覆盖结果。
```

反转依据是同一制动破绽被利用；赤狐通过让线和路线选择脱险，没有突然治疗手腕或获得新超能力。关键状态可以继续带到下一段。

## 示例 F：6 秒三人同框，轮流介入而非同时缠斗

说明人数不是强制预演阈值。选择一镜到底和错峰动作，不宣称已验证模型执行。若用户需要三条精确交叉路线，另按平台能力建议分镜或预演。

```text
三维动画，6 秒，一镜到底，无台词。小牛保持四足，面向巷道右侧出口；灰狼在画面右前方拦截，黑狼在左后方追来，相距两个身位。墙上的木窗是地标，巷道只向右延伸。摄影机在巷道南侧平行跟拍，始终看清小牛四足、灰狼和黑狼的前后距离。

0–2s｜灰狼从右前方向左跃扑。小牛后足蹬地，压低头部，以角外侧顶到灰狼胸侧，将其推向巷道北墙方向；前足随即落稳。黑狼仍从左后方奔近，尚未进入接触范围。相机向右跟随，保留决定性接触与灰狼偏离路线的结果。

2–4s｜灰狼沿北墙滑落到路旁。黑狼此时从后方追到，伸前爪扑向小牛背部；小牛不回头硬撞，四足连续蹬地向右加速，黑狼前爪从牛背后方落空，落地时前肢压缩缓冲。摄影机连续向右移，不跳到另一侧。

4–6s｜小牛继续奔向右侧出口，四足交替支撑，尾巴滞后甩动。黑狼落稳后追起，灰狼仍在后方北墙边撑地；同一木窗留在背景，显示各自位置。末尾保留持续向右的运动，便于下一段续接。
```

## 示例 G：峰值图被指定为首帧，起势已经过去

假设用户实际提供并指定一张“守卫双掌贴住胸甲、机械兽前足刚离地”的图为首帧；这里仅演示文字，不编造平台素材编号。

```text
4 秒，沿用用户首帧中的角色、材质、相对位置与接触状态。守卫双掌已经贴住机械兽胸甲，机械兽前足已离地。摄影机从首帧观察侧稍向后拉开。守卫顺当前前倾重心继续伸髋推出，机械兽从接触处向后滑离，随后前足落地压缩缓冲，四足刮地制动；胸甲接触余光减弱，尘屑沿滑行方向继续漂移。结束时双方仍相向，守卫掌心能量变弱，不重演举掌、蓄力或刚贴上胸甲的过程。
```
