# 失败模式与修正

用于复杂动作的写前检查或用户提供成片后的局部修正。以下是排查假设与编排手段，不是已验证的模型诊断、失败概率或质量保证。没有成片时说“可降低描述歧义”，不要声称已经发生画面错误。

## 先定位，再改一个主要变量

有成片时确认出错的时间、接触或空间变化；只有文字时找不清楚或互相冲突的要求。保留已经有效的角色、画风、时长和既定结果，优先改导致问题的描述。区分文字约束不足、素材冲突、平台不支持与生成随机偏差。

| 可见问题或文本风险 | 先检查 | 优先修正 |
| --- | --- | --- |
| 左右关系突然翻转、追击方向丢失 | 混淆场内方向与画面左右；切镜/绕拍未交代 | 用地标维持场内关系，注明当前观察侧；越轴用连续机位或建立镜交代，允许真实换位 |
| 肢体融合、手脚归属混乱 | 多条肢体路径同时交叉；接触部位和主人不明 | 一个峰值集中写决定性作用点；标明谁的哪只手碰到谁的哪里，其余动作错开或省略无关描述 |
| 抱摔悬空、抓握无受力 | 为了精简删掉了必要支撑 | 保留支撑脚、抓握和失衡先后；“一个主要作用关系”不等于只允许一个物理接触点 |
| 武器穿身或突然换手 | 持物与身体路径冲突；刀具在旁支动作中去向不明 | 指明持手、刀尖方向和独立路径；不参加本次作用时贴身收住，换持、收刀或掉落要有过程 |
| 高速动作变成缓慢摆姿 | 全是静态形容、没有启动和余势；慢动作持续过长 | 用明确的蹬地、压缩、释放、位移与制动替换装饰；放慢只突出必要拍点 |
| 体型差或四足形态丢失 | 交锋描述与角色形态冲突；参考素材互相矛盾 | 在易丢区别的镜头复现对照或支撑形态；核对资产，不要求四足角色做未设定的人形动作 |
| 能量把服装、皮毛整体改色 | 混淆发光、受光与材质色；不同镜头能量阶段冲突 | 指定光源位置、邻近受光和消退；材质底色仍沿用资产，大范围照明只在情节需要时扩展 |
| 伤势、喘息、装备损耗跨镜恢复 | 下一镜只复制最初角色档案 | 携带上一镜实际状态；恢复、拾取、修复需要已设定过程 |
| 反转突然、胜负像随机交换 | 缺少已建立的破绽或规则 | 提前露出条件，让角色利用它；删掉临时底牌，保留用户规定结果 |
| 一镜到底出现暗切或跳位 | 按分镜语法写了独立机位，摄影机无法连续到达 | 改为阶段语法，明确摄影机如何移动与让开遮挡；减少并发事件，尊重禁止切镜的要求 |
| 多人互相穿越、第三人闲置 | 同一时刻多条独立攻击线、交叉路径与遮挡 | 写清当前进攻者、受作用者、其余人的等待/绕行和加入时机；按需分阶段或用已有预演 |
| 画面有美术、动作没执行 | 一条描述填了太多独立事件；资产、动作和相机输入冲突 | 保留目标攻防与后果，移走重复美术；核对素材各管什么，不保证只缩短就会变好 |

接触数或同框人数不能单独决定是否拆镜。一镜到底优先错开接触、稳定观察位；用户允许剪切且动作仍难辨时再拆镜。复杂调度可建议位置图、动作分镜或真正的预演录制，但静态白模图不等于包含运动轨迹的视频。

## 把修正写成正向动作

优先描述“右手短刀朝下贴在身侧；左肩被抓后回步卸力”，再按已确认的平台能力补必要排除项。不要只堆“无融合、无穿模、无变形”等负面词，或虚构平台支持独立负面提示词字段。

## 若用户授权生成验证

使用同一剧情、同一资产、同一已确认模型和生成设置，对比原提示词与一次局部修正；如果支持固定随机种子可固定，否则用多次样本避免单片定论。复杂路径可以另对比已提供的分镜或预演输入，不能把新增素材的收益全归给文字变短。

观察：动作可读、接触与受力、体型/形态、空间与状态连续、是否达成既定结果。记录实际模型、设置、样本数和看见的问题，区分文本检查与视频实测。用户没有授权时不付费、不生成、不自动转平台。
