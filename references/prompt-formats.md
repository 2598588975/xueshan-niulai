# 基础提示词格式

这份文件保留学习画布后归纳出的三种格式、字段次序及用途。骨架经过归并整理，方括号内容是待替换字段，不是原作者全文逐字转录。生成最终提示词时替换字段并删去无关项；不要把空白模板直接交付成完成稿。

## 格式 A：基础设定＋时间轴

适用：总时长明确、事件较多、需要控制情绪转折和镜头顺序的动画段落。

```text
【基础设定】
[动画类型与整体视觉风格]；[画幅、总时长及已知生成参数]。
角色：[角色身份、固定外观、体型差异、服装材质；有真实参考时注明绑定]。
场景：[地形、前中后景、交战区域、可参与动作的环境物]。
光线与色彩：[主光方向、环境光、角色与背景区分、能量光对物体的影响]。
开场关系：[双方相对位置、朝向、距离、当前姿态和故事目标]。
连续性：[确有必要的持物、服装、能量与环境状态]。

0–[t1]s｜[景别、机位、主要运镜和速度]。[主体准备或起势]；[对手反应]；[动作与环境动态]。[需要的声音或台词]。
[t1]–[t2]s｜[镜头衔接]。[攻击路径与动作发动]；[闪避、格挡或接触过程]；[重心和位置变化]。[声音]。
[t2]–[t3]s｜[使关键动作可见的机位]。[局势转折或反击]；[受力反馈、衣物与粒子滞后]。[声音]。
[t3]–[总时长]s｜[交代后果的构图和运镜]。[落地、滑移、制动或收势]；[最终人物关系与情绪]；[下一段衔接状态]。
```

应用要点：

- 段数与拍点由内容决定。原画布部分条目使用约 1.5 秒一段，学习的是按时间组织信息的方法，不要求所有打戏都等间隔分段。
- 接触与位移往往需要不同信息量。允许长准备、短爆发，也允许长追击后短暂静止。
- 用户给定总时长时，各区间无空缺、无重叠，加总准确。每一行可以是一个镜头，也可以是一镜到底中的一个阶段，需明确是哪一种。
- 总设定已说明的毛发、材质等，不在每一行完整重复。

## 格式 B：角色档案＋画面设定＋动态执行

适用：近身交锋、动作峰值、体型差异、复杂运镜、腾空与能量爆发。此格式把“要看见什么”与“如何发生”放在相邻两段，便于做图、视频和分镜参考。

### 保留原组织方式的基础骨架

```text
角色 A
[身份与固定造型；体型、服装和材质；姿态习惯、表情特征；实际参考绑定]

角色 B
[身份与固定造型；与 A 的体型和动作差异；实际参考绑定]

镜头 [编号]：[本镜头的事件与作用]

画面设定（明确：起始帧 / 动作峰值关键帧）：
[画面构图：景别、机位] +
[调用角色：本镜头出现的人物或有效参考] +
[人物空间与互动关系：位置、朝向、距离、接触关系] +
[微表情：眼神、呼吸、嘴部或面部张力] +
[场景前中后景：地形、遮挡、地标、运动空间] +
[光影与大气：主光、环境光、空气透视、粒子] +
[视觉风格与材质：符合项目的动画渲染、毛发、衣物、表面质感] +
[镜头感及已知技术参数：焦段感、景深、画幅等]

动态执行：
[明确摄影机起点、轨迹、速度及结束构图] +
[主体的具体动作：发力、方向、路径与节奏] +
[双方肢体互动过程：对手反应、接触或错身、重心和位移] +
[环境物理动态：衣物、毛发、尘雪水、碎屑及余势] +
[音效与必要音乐：出现时机、强弱、与动作同步] +
[必要台词、说话者和语气；无台词时可省略] +
[本镜头时长与最终姿态]
```

### 直接投喂时的精简版

```text
[总设定：角色、参考绑定、动画风格、环境和开场关系。]

镜头 1｜[时长]｜[本镜头事件]
画面：[景别和机位]，[人物空间关系和情绪]，[与动作有关的场景层次、光线与材质]。
动态：镜头从[起点]以[速度]沿[路径]移动；[主体起势与动作路径]；[对手反应与接触/闪避]；[重心、受力方向与落点]；[衣物及环境反馈]；结束于[可衔接姿态]。
声音：[与动作对应的环境、运动、接触音；必要音乐和短台词]。

镜头 2｜[时长]｜[由上一动作触发的下一事件]
画面：……
动态：……
声音：……
```

“+”用于显示字段关系，成稿可以合并成自然语句。角色档案定义一次；除非身份或状态变化，不在每个镜头复制整段。

### 关键帧与时间起点

- **起始帧**：动态段从此刻继续，已发生的动作不再重新发生。
- **动作峰值关键帧**：用于表达接触瞬间或视觉目标；动态段需要写明如何从初始姿态到达该瞬间，再写余势。
- 用户把峰值图指定为图生视频首帧时，必须从该姿态往后写。若还需要前置蓄力，另设计起始帧或前一段。
- 一镜到底可用同一格式，将多个“镜头”改写为同一镜头的阶段，并连续说明摄影机如何到达下一个观察位置。

## 格式 C：角色＋单一事件

适用：复杂打斗之间的落点、反应和过桥动作，如从碎石中起身、抬眼发现目标、拍拍衣服、接住物品或一句喊话。

```text
[角色及实际参考绑定]，处于[明确位置、姿态和当前状态]。
[一个清楚动作及先后过程]，带来[可见结果或状态变化]。
[必要景别与简短运镜]；[关键微表情、衣物或环境反馈]。
[确有需要的台词、声线与声音]。[已知时长]。
```

短事件只保留能改变画面的内容。一个简单动作无需扩写成多段打斗。

## 格式选择与共享约束

| 当前任务 | 优先格式 | 成稿重点 |
| --- | --- | --- |
| 按秒控制一段剧情和攻防转折 | A | 时间、节奏、连续状态 |
| 设计一组具有明确接触和运镜的动作镜头 | B | 画面目标、动作执行、身体与环境反馈 |
| 单一衔接、反应或状态变化 | C | 简洁、单一结果、下一镜入口 |
| 用户已有固定格式 | 用户格式 | 将本技能方法填进原字段 |

画幅、分辨率、时长上限、参考标签和模型参数只写已知值。没有实际绑定时使用角色名称；模板中的参考字段不能冒充平台已经接受的引用。来源格式和原创示例分别保留，方便以后复用时知道哪些是观察、哪些是新设计。
