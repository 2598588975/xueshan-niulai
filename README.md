# 雪山牛来 · 动画打戏与对局 Skill

用于将剧情、动作梗概、角色与场景参考，整理成中文 AI 视频提示词。重点覆盖三维动画、拟人角色、体型悬殊近战、高速追击、腾空交锋和能量爆发，并设计优势变化、反转依据、状态损耗与跨镜连续性。

对局推进：**目标与赌注 → 优势变化 → 有前因的反转 → 可见代价 → 本段结果。**

动作组织：**人物与空间关系 → 意图与蓄力 → 动作路径 → 接触或闪避 → 重心变化 → 身体及环境反馈 → 收势或下一次进攻。**

## 使用

将本仓库下载或克隆到本地技能目录中的 `xueshan-niulai` 文件夹，确保结构为 `xueshan-niulai/SKILL.md`，并保留 `agents/`、`references/` 两个目录。

调用示例：

```text
用 $xueshan-niulai，把这段剧情写成 15 秒动画高速打斗提示词。
角色 A 体型厚重，角色 B 灵巧；场景是雨后的石桥。
重点表现高速攻防、追拍运镜、接触反馈，以及利用已出现的破绽脱身；已有损耗持续到结尾。
```

也可以指定一镜到底、固定时长、已有参考图或自己的提示词格式。技能根据人物和场景重新设计动作，不要求使用雪山或牛角色。

## 学习来源

方法来自对油条的 [《牛来-雪山决战之巅》](https://www.liblib.tv/detail/2180f1ab1d4c4d4da547df21a5543317) 画布提示词及部分生成画面的学习。

本仓库保存的是整理后的创作方法与格式参考。格式骨架经过归并，示例均为原创演示，不是原作者完整提示词的逐字转录。以理解、学习和迁移为主。

已检查字段、内部引用、示例时间轴与文件完整性。自带 quick_validate.py 因环境缺少 PyYAML 未完成，使用限定 YAML 字段检查；尚未进行实际视频生成测试。按秒信息预算属于编排建议，不是平台上限或出片效果保证。
